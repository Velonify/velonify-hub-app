# Velonify Hub für Mandanten

Veröffentlicht den Velonify Hub im Mandantenmodus (`VITE_MANDANTEN=1`) auf **app.velonify.de**. Hier liegt nur der Workflow, der Code kommt aus [Velonify/velonify-crm](https://github.com/Velonify/velonify-crm) (`main`), Einrichtung dort in `PLATTFORM.md`.

Repo-Variablen: `MANDANTEN_CLIENT_ID` (OAuth-Client im Projekt velonify-hub-app), `CRM_API_URL`.
